## O que eu faço

Lidero a engenharia de um portfólio de produtos na SEC365. Coordeno desenvolvedores em
frentes paralelas, quebro escopo em trabalho executável, reviso entrega e continuo
escrevendo código.

| Frente | O que envolve |
| --- | --- |
| Arquitetura e backend | Serviços em Python com FastAPI, filas e workers assíncronos, modelagem de dados, migrations, APIs sob carga real |
| Plataformas web | Painéis operacionais em React com TypeScript: tabelas grandes, dado em tempo real, uso contínuo |
| Sistemas com IA | Agentes e pipelines com LLM em produção: orquestração, avaliação de saída, custo por execução |
| Automação e coleta | Playwright, scraping resiliente, OCR |
| Infra e entrega | Docker Compose multi-serviço, deploy em VPS e edge, CI/CD, observabilidade |
| Coordenação técnica | Distribuir por capacidade, revisar entrega, desbloquear quem travou, manter prazo |

Os produtos são desenvolvidos sob contrato e não são públicos.
